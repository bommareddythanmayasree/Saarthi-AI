Common Issues & Solutions

If you see "auth/unauthorized-domain" error:

  1. Go to Firebase Console - Authorized Domains
  2. Add localhost to the list
  3. Add 127.0.0.1 to the list
  4. Refresh this page and try again

If you see "auth/operation-not-allowed" error:

  1. Go to Firebase Console - Sign-in Methods
  2. Find "Google" in the list
  3. Click on it and enable it
  4. Save and try again
